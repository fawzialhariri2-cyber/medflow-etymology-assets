# MedFlow Etymology Assets

Asset pack for the MedFlow **Etymology Course / The Shape Code**.

This repository exists to support the approved Chapter 1 / Module 1 production workflow. It is not a replacement for the course source, the slide deck, or the Notion migration manifest.

## Start here

1. Read `AGENTS.md` for the current Project Fawzi production rules.
2. Read `README_FIRST.md` for the asset-hosting workflow.
3. Use `IMAGE_MANIFEST.csv` as the machine-readable asset map.
4. Follow `CROP_AND_USE_RULES.md` when placing/cropping images.
5. Use `GEMINI_IMAGE_INTEGRATION_PROMPT.txt` only inside the existing strong deck conversation/workflow; do not request a full redesign.

## Current root-family pack

The current image set covers 12 families:

- Arcus / Arcuate
- Sagitta / Sagittal
- Falx / Falciform
- Trochlea / Trochlear
- Serra / Serratus
- Malleus / Malleolus
- Incus
- Stapes / Stapedius
- Stylos / Styloid
- Vomer
- Xiphos / Xiphoid
- Clavis / Clavicula / Clavicle

Each family is represented by an analogy image and an anatomy image in `assets/`.

## Locked visual direction

The approved Workshop deck is the visual master: navy/gold, cinematic, with the official MedFlow identity. Production should improve weak images/crops and faulty slides **without rebuilding the whole deck**.

Preferred pattern when useful: real anatomy + the naming analogy side by side.

## Production rule

Audit against the source → identify faulty slides → patch only those slides → regenerate only those slides → merge the best result → final coverage check.

For project-wide continuity, the canonical portfolio handoff is maintained in Notion under **Fawzi — Execution Control Tower**.
